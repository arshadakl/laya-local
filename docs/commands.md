# Supported Commands

## Malayalam Commands

| Command | Action |
|---------|--------|
| Chrome തുറക്കൂ | Open Google Chrome |
| VS Code തുറക്കൂ | Open Visual Studio Code |
| Terminal തുറക്കൂ | Open Windows Terminal |
| Downloads folder തുറക്കൂ | Open Downloads folder |
| Documents folder തുറക്കൂ | Open Documents folder |
| ശബ്ദം കുറയ്ക്കൂ | Decrease volume |
| ശബ്ദം കൂട്ടൂ | Increase volume |
| കമ്പ്യൂട്ടർ ലോക്ക് ചെയ്യൂ | Lock computer |
| ഷട്ട് ഡൗൺ ചെയ്യൂ | Shutdown computer |
| Discord തുറക്കൂ | Open Discord |
| Spotify തുറക്കൂ | Open Spotify |
